# 🎮 幼兒教育遊戲平台 Kids Games Platform

一個專為 4-13 歲兒童設計的網頁遊戲平台，包含 16 款教育遊戲，支援兩個年齡組別的差異化體驗。

## 🌟 專案特色

- **年齡分組設計**：針對 4-6 歲（寶寶樂園）和 7-13 歲（探索樂園）提供不同難度
- **響應式設計**：支援桌面與移動設備
- **圖像化介面**：4-6 歲組別採用大圖示、無文字選項的設計
- **多樣化遊戲**：涵蓋邏輯、記憶、語言、數學、常識等多個領域
- **進度追蹤**：記錄遊戲成績和完成時間
- **家長控制**：提供遊戲數據統計和管理功能

## 🛠️ 技術架構

### 前端技術棧

- **框架**：React 18 + TypeScript
- **構建工具**：Vite
- **路由**：React Router v6
- **狀態管理**：Zustand
- **UI 框架**：TailwindCSS
- **動畫**：Framer Motion
- **代碼規範**：ESLint + TypeScript ESLint

### 專案結構

```
kids-games/
├── src/
│   ├── components/       # 共用組件
│   │   └── ui/          # UI 基礎組件
│   ├── pages/           # 頁面組件
│   │   └── games/       # 遊戲頁面
│   ├── store/           # Zustand 狀態管理
│   ├── utils/           # 工具函數與常量
│   ├── App.tsx          # 主應用組件
│   └── main.tsx         # 應用入口
├── public/              # 靜態資源
└── vercel.json          # Vercel 部署配置
```

## 📦 安裝與運行

```bash

npm install

# 啟動開發服務器
npm run dev

# 構建生產版本
npm run build

# 預覽生產構建
npm run preview
```

## 🎯 核心功能

### 年齡適應性設計

**4-6 歲組別特點：**
- 大圖示設計（text-7xl ~ text-9xl）
- 純圖像選項，無文字標籤
- 簡化遊戲規則
- 較少的選項數量
- 更長的反應時間

**7-13 歲組別特點：**
- 圖文並茂
- 更複雜的遊戲機制
- 更多的選項和挑戰
- 知識性內容增強

### 遊戲功能

- **成績記錄**：自動保存分數、完成時間、正確率
- **難度調整**：根據年齡組別自動調整
- **即時反饋**：操作即時視覺和文字回饋
- **進度追蹤**：記錄遊戲歷程

### 家長控制

- 查看遊戲統計
- 重置遊戲數據
- 管理遊戲設定
