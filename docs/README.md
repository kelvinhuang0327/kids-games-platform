# 幼兒網頁遊戲平台 (Kids Games Platform)

**版本**: v0.2 (純前端 MVP)
**狀態**: Phase 3 進行中（較難遊戲開發）
**分支**: `001-kids-games-platform`
**已完成遊戲**: 5/8 款（簡單 3 + 中等 2）

## 專案簡介

幼兒網頁遊戲平台是一個專為兒童設計的教育遊戲平台 MVP，使用純前端技術實作：

- ✅ 分齡設計 (4–6 歲 / 7–13 歲)
- ✅ 本地儲存遊戲進度（LocalStorage）
- ✅ 零廣告、無追蹤、重視隱私保護
- ✅ 跨裝置響應式設計
- ✅ 5 款遊戲已完成（簡單 3 + 中等 2）
- 🔄 3 款較難遊戲開發中（僅 7-13 歲）

---

## MVP 核心特色

### ✅ 為兒童設計

- 直覺易用的介面
- 大按鈕設計
- 明亮活潑配色
- 流暢動畫回饋（Framer Motion）

### ✅ 安全與隱私

- 無個人資料收集
- 本地 LocalStorage 儲存遊戲進度
- 無第三方追蹤、無 Cookie
- 零伺服器依賴（純前端）

### ✅ 家長控制

- 數學題驗證（3+5=?）
- 遊戲統計顯示
- 使用時間追蹤
- 資料清除功能

- **型別安全**：TypeScript 確保程式碼品質
- **測試完善**：70% 覆蓋率，31+ 測試案例
- **簡潔依賴**：僅 5 個核心依賴套件（React, Zustand, Framer Motion, React Router, Tailwind）

## 技術堆疊（MVP）

### 核心依賴（5 個）

```json
{
  "react": "^18.2.0",
  "react-dom": "^18.2.0",
  "react-router-dom": "^6.20.0",
  "zustand": "^4.4.7",
  "framer-motion": "^10.16.16"
}
```

### 開發工具

- **React 18**：組件化 UI 架構
- **TypeScript**：型別安全、易維護
- **Vite 5**：極快建構工具（<2s 啟動）
- **Zustand**：輕量狀態管理（比 Redux 少 80% 程式碼）
- **Tailwind CSS**：快速樣式開發
- **Framer Motion**：流暢動畫系統
- **Vitest**：快速單元測試
- **React Testing Library**：組件測試

### 未來完整版技術堆疊

- **後端**：NestJS 10+ (Node.js 20 LTS)
- **資料庫**：PostgreSQL 15+ (Prisma ORM)
- **快取**：Redis 7+
- **測試**：Playwright (E2E)

## 快速開始

### 1. 安裝依賴

```bash
npm install
```

### 2. 啟動開發伺服器

```bash
npm run dev
```

預設會在 `http://localhost:5173` 啟動

### 3. 執行測試

```bash
npm run test
```

### 4. 建構生產版本

```bash
npm run build
```
