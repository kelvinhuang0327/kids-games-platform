# 幼兒網頁遊戲 - 內容與功能規格 (Spec Kit)

**文件版本**: v1.0
**更新日期**: 2025-10-27
**狀態**: Draft

---

## 1. 專案總覽 (Overview)

### 1.1 文件目的
本文件為「幼兒網頁遊戲平台」的內容與功能規格書，旨在明確定義：
- 產品功能範圍與特性
- 用戶體驗流程與互動設計
- 內容分級與教育目標
- 安全與隱私保護機制

### 1.2 範圍與預期讀者
**適用範圍**:
- 產品經理與專案管理團隊
- UI/UX 設計師
- 教育內容策劃團隊
- 行銷與業務團隊

**預期讀者應能理解**:
- 產品功能需求與用戶故事
- 介面互動流程
- 內容分級邏輯

### 1.3 開發背景與目標

#### 背景
- 數位學習需求增長，家長尋求安全且具教育價值的線上內容
- 市場缺乏針對華語兒童、分齡清晰且無廣告的優質遊戲平台
- 需要符合國際兒童隱私保護標準的解決方案

#### 目標
1. **教育目標**: 透過遊戲化學習，培養 4-13 歲兒童的認知、邏輯、創意能力
2. **安全目標**: 提供零廣告、無不當內容、家長可控的安全環境
3. **體驗目標**: 直覺易用的介面，適合兒童自主操作
4. **技術目標**: 跨裝置響應式設計，流暢的遊戲體驗

## 2. 系統與功能總覽 (System & Feature Overview)

### 2.1 分齡模組設計

#### 2.1.1 幼兒組 (4-6 歲)
**認知特性**:
- 視覺導向，需要大型按鈕與明確圖示
- 專注力短，遊戲時長建議 5-10 分鐘
- 需要即時正向回饋與語音引導

**遊戲特色**:
- 簡單拖放操作
- 豐富音效與動畫回饋
- 語音指示與鼓勵
- 無文字或最少文字

#### 2.1.2 兒童組 (7-13 歲)
**認知特性**:
- 可理解規則與策略
- 專注力提升，可進行 15-30 分鐘遊戲
- 開始建立競爭意識與成就感

**遊戲特色**:
- 多層次挑戰與關卡設計
- 積分與成就系統
- 複雜邏輯與問題解決
- 可包含適量文字說明

### 2.2 遊戲列表與功能說明

#### 2.2.1 拼圖遊戲 (Puzzle)
**適用年齡**: 4-6 歲（簡易）、7-13 歲（進階）

**功能描述**:
- **4-6 歲版本**:
  - 4-9 片大塊拼圖
  - 拖放操作，自動吸附對齊
  - 完成播放慶祝動畫與音效
  - 主題: 動物、交通工具、水果

- **7-13 歲版本**:
  - 16-64 片拼圖
  - 可旋轉拼圖塊（進階模式）
  - 計時與最佳紀錄
  - 主題: 風景、名畫、科學圖解

**學習目標**:
- 空間認知能力
- 手眼協調
- 視覺記憶與辨識

#### 2.2.2 迷宮遊戲 (Maze)
**適用年齡**: 4-6 歲（引導式）、7-13 歲（挑戰式）

**功能描述**:
- **4-6 歲版本**:
  - 簡單路徑，單一正解
  - 鍵盤方向鍵或點擊控制
  - 卡通角色引導（小動物、小汽車）
  - 收集道具增加趣味

- **7-13 歲版本**:
  - 多岔路、需策略規劃
  - 計時挑戰
  - 障礙物與機關設計
  - 多種解法與最優路徑挑戰

**學習目標**:
- 邏輯推理
- 空間導航能力
- 計劃與執行力

#### 2.2.3 互動漫畫 (Interactive Comic)
**適用年齡**: 4-6 歲（語音為主）、7-13 歲（文字為主）

**功能描述**:
- 分鏡式故事呈現
- 點擊互動元素觸發動畫
- 語音旁白（4-6 歲）
- 選擇式劇情分支（7-13 歲進階）
- 主題: 品格教育、科學知識、生活常識

**學習目標**:
- 閱讀理解
- 創意想像
- 價值觀培養

#### 2.2.4 數學挑戰 (Math Challenge)
**適用年齡**: 7-13 歲

**功能描述**:
- **低年級 (7-9 歲)**:
  - 加減法運算（100 以內）
  - 視覺化數量概念（圖形計數）
  - 簡單應用題

- **高年級 (10-13 歲)**:
  - 乘除法、分數、小數
  - 幾何基礎認識
  - 邏輯推理題

**學習目標**:
- 數學運算能力
- 問題解決技巧
- 邏輯思維

#### 2.2.5 程式邏輯 (Coding Logic)
**適用年齡**: 7-13 歲

**功能描述**:
- 視覺化程式積木（類 Scratch）
- 任務: 讓角色移動至目標
- 概念: 序列、迴圈、條件判斷
- 關卡式學習，難度漸進

**學習目標**:
- 運算思維
- 問題拆解能力
- 邏輯建構

#### 2.2.6 EdX 推薦遊戲
**適用年齡**: 7-13 歲

**功能描述**:
- 精選教育遊戲連結或嵌入
- 與 EdX 等教育平台合作內容
- 主題: STEAM、語言、藝術

**學習目標**:
- 多元化學習接觸
- 優質外部資源整合

### 2.3 主要功能與介面流程

#### 2.3.1 首頁入口 (Landing Page)
**功能**:
- 顯示兩個大型分齡入口按鈕
  - "4-6 歲 寶寶樂園" (大圖示、卡通風格)
  - "7-13 歲 小學天地" (活潑圖示、知識風格)
- 家長模式入口（小圖示於右上角）

**流程**:
```
用戶進入網站
    ↓
選擇年齡組別
    ↓
進入對應遊戲大廳
```

#### 2.3.2 遊戲大廳 (Game Hall)
**功能**:
- 顯示該年齡組可用遊戲（卡片式排列）
- 每個遊戲卡片包含:
  - 遊戲圖示
  - 遊戲名稱
  - 簡短說明（可語音播放）
  - 開始遊戲按鈕
- 返回首頁按鈕

**流程**:
```
遊戲大廳
    ↓
選擇遊戲
    ↓
進入遊戲介面
    ↓
完成/退出
    ↓
返回遊戲大廳
```

#### 2.3.3 遊戲內介面 (In-Game Interface)
**功能**:
- 遊戲主要畫面（全屏或 16:9 比例）
- 控制按鈕:
  - 暫停
  - 重新開始
  - 返回大廳
  - 音效開關
  - 說明/提示
- 進度指示（如適用）
- 計分/計時（如適用）

**流程**:
```
開始遊戲
    ↓
遊戲進行中
    ↓
完成 → 顯示結果畫面（鼓勵動畫、積分、建議下一步）
    ↓
選擇: 再玩一次 / 選擇其他遊戲 / 返回大廳
```

## 3. 家長與安全機制 (Parental & Safety)

### 3.1 家長模式 (Parental Mode)

#### 3.1.1 進入方式
- 首頁右上角「家長專區」按鈕
- 需要簡單驗證（例: 簡單數學題、滑動解鎖）
- 防止兒童誤入

#### 3.1.2 家長控制台功能
1. **遊戲時間管理**
   - 設定每日遊戲時間限制
   - 設定可遊戲時段
   - 超時溫和提醒與鎖定

2. **內容篩選**
   - 選擇允許/禁用特定遊戲
   - 年齡組別確認與調整

3. **學習報告**
   - 遊戲時長統計（每日/每週）
   - 各遊戲完成度與表現
   - 學習軌跡圖表
   - 建議與提示

4. **帳號設定**
   - 兒童暱稱設定（無需真實姓名）
   - 頭像選擇
   - 偏好設定

### 3.2 安全機制

#### 3.2.1 內容安全
- 所有內容經教育專家審核
- 無暴力、恐怖、不當元素
- 無外部連結（除經審核的教育夥伴）
- 無廣告、無內購

#### 3.2.2 互動安全
- 無聊天功能
- 無社群互動
- 無個人資料收集（姓名、照片、位置等）
- 無需註冊或登入（本地儲存進度）

#### 3.2.3 技術安全
- HTTPS 加密連線
- 無第三方追蹤
- 本地儲存遊戲進度（無雲端上傳）
- 定期安全檢測

### 3.3 隱私政策

#### 3.3.1 資料收集政策
**不收集**:
- 個人身份資訊
- 位置資訊
- 照片或錄音
- 聯絡方式

**僅本地儲存**:
- 遊戲進度
- 設定偏好
- 統計數據（不上傳）

#### 3.3.2 合規標準
- **COPPA** (Children's Online Privacy Protection Act): 美國兒童線上隱私保護法
- **GDPR-K** (針對兒童的一般資料保護規範)
- 台灣個人資料保護法

#### 3.3.3 家長權利
- 隨時檢視本地儲存資料
- 一鍵清除所有資料
- 透明的隱私說明（家長專區提供）

## 4. UI/UX 設計 (UI/UX Design)

### 4.1 分齡介面設計

#### 4.1.1 幼兒組 (4-6 歲) 介面特點
**視覺設計**:
- 大型按鈕（最小 80x80px）
- 圓角設計，柔和色彩
- 高對比度
- 大量插圖與圖示，最少文字

**互動設計**:
- 簡單拖放
- 點擊回饋明顯（音效+動畫）
- 語音引導
- 容錯性高（無懲罰機制）

**色彩方案**:
- 主色: 明亮、飽和
- 背景: 淺色、柔和
- 按鈕: 彩虹色系、易區分

#### 4.1.2 兒童組 (7-13 歲) 介面特點
**視覺設計**:
- 按鈕尺寸適中（60x60px 以上）
- 更多資訊呈現
- 扁平化風格，現代感
- 文字說明輔以圖示

**互動設計**:
- 鍵盤與滑鼠支援
- 複雜操作（拖放、旋轉、組合）
- 成就與進度視覺化
- 挑戰與回饋機制

**色彩方案**:
- 主色: 活潑但不刺眼
- 背景: 白色或淺灰
- 強調色: 用於互動元素

### 4.2 無障礙支援 (Accessibility)

#### 4.2.1 視覺無障礙
- 高對比模式
- 色盲友善配色
- 可調整字體大小
- 清晰的視覺層級

#### 4.2.2 操作無障礙
- 鍵盤完整導航
- 觸控放大區域
- 語音提示與說明
- 操作容錯與復原

#### 4.2.3 認知無障礙
- 一致的導航邏輯
- 清晰的視覺提示
- 簡單的語言表達
- 多重感官回饋

## 5. 響應式設計 (Responsive Design)

### 5.1 裝置支援
- **桌面** (Desktop): 1920x1080, 1366x768
- **平板** (Tablet): iPad (1024x768), Android Tablets
- **手機** (Mobile): 基本支援，但建議使用平板或桌面以獲得最佳體驗

### 5.2 斷點設計
- **大屏** (> 1200px): 3 欄遊戲卡片排列
- **中屏** (768-1199px): 2 欄排列
- **小屏** (< 767px): 1 欄排列，放大按鈕尺寸

### 5.3 觸控優化
- 觸控目標最小 44x44px (符合 Apple HIG 與 Material Design 建議)
- 手勢支援: 點擊、長按、拖放
- 避免懸停(hover)依賴
