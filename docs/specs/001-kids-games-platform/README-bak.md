## 核心功能摘要

### 1. 年齡分段內容（FR-001 至 FR-005）

**為什麼重要**: 確保內容適合兒童發展階段

- ✅ 兩個年齡組：4-6歲 和 7-13歲
- ✅ 動態難度調整
- ✅ 適齡回饋和獎勵系統
- ✅ 家長可控制的年齡組轉換

### 2. 家長控制與隱私（FR-010 至 FR-026）

**為什麼重要**: COPPA/GDPR 合規和家長信任

**時間管理**:
- ⏰ 每日/每週時間限制設定
- ⏰ 5分鐘和1分鐘警告
- ⏰ 10秒精確度的時間追蹤
- ⏰ 單一會話執行（一次一個兒童）

**隱私保護**:
- 🔒 最小 PII 收集（僅名字和出生日期）
- 🔒 AES-256 加密敏感資料
- 🔒 家長認證保護的資料匯出
- 🔒 GDPR 刪除權（CASCADE DELETE）

### 3. 多模式遊戲互動（FR-006 至 FR-009）

**為什麼重要**: 維持參與度和全面技能發展

- 🎮 **拖放拼圖** - 訓練精細運動技能和空間推理
- 🎮 **按鈕問答** - 訓練知識和快速決策
- 🎮 **角色扮演/動作** - 訓練敘事和運動協調
- 🔊 所有遊戲都有語音指引和動畫回饋

### 4. 無障礙合規（FR-027 至 FR-032）

**為什麼重要**: 確保所有兒童都能使用平台

**WCAG 2.1 AA 支援**:
- 👁️ 色盲模式（氘色盲、紅色盲、藍黃色盲）
- 👁️ 可調整文字大小（小、中、大、特大）
- 👁️ 高對比模式
- ⌨️ 完整鍵盤導航
- 📢 ARIA 標籤用於螢幕閱讀器
- 👆 44x44px 最小觸控目標

### 5. 學習分析（FR-033 至 FR-037）

**為什麼重要**: 家長參與度和展示教育價值

- 📊 技能發展追蹤（記憶、空間推理、解決問題、語言）
- 📊 隨時間的進度趨勢
- 📊 詳細活動報告
- 📊 可匯出的學習報告

### 6. 測試與品質（FR-038 至 FR-042）

**為什麼重要**: 確保平台可靠性和安全性

- ✅ 80% 自動化測試覆蓋率
- ✅ 端對端測試覆蓋所有互動類型
- ✅ 每個年齡組 10+ 名兒童的真實使用者測試
- ✅ 自動化無障礙測試（axe-core）

## 資料模型架構

### 實體關係圖

```
家長帳號 (1) ──< (多) 兒童檔案
兒童檔案 (1) ──< (多) 遊戲時段
兒童檔案 (1) ──── (1) 無障礙檔案
兒童檔案 (1) ──── (1) 家長控制設定
遊戲模組 (1) ──< (多) 遊戲時段
兒童檔案 (1) ──< (多) 學習進度
```

### 核心實體（7個）

1. **ParentAccount** - 電子郵件、密碼、PIN、訂閱狀態
2. **ChildProfile** - 名字、出生日期、年齡組、頭像
3. **GameModule** - 名稱、年齡組、互動類型、技能
4. **PlaySession** - 時間、完成狀態、分數、指標
5. **AccessibilityProfile** - 色盲模式、文字大小、對比
6. **ParentalControlSettings** - 時間限制、警告、寬限期
7. **LearningProgress** - 技能、活動、成功率、改善

## API 端點架構

### 8 個類別，25+ 端點

```
/auth/*              - 認證（註冊、登入、刷新、PIN）
/parent/*            - 家長管理（檔案、匯出、刪除）
/children/*          - 兒童管理（CRUD）
/games/*             - 遊戲目錄（列表、詳情、篩選）
/sessions/*          - 遊戲時段（開始、心跳、結束）
/children/*/controls - 家長控制（時間限制、使用情況）
/children/*/learning-progress - 學習分析（報告、活動）
/children/*/accessibility - 無障礙設定
```

完整 OpenAPI 3.0 規格：[contracts/openapi.yaml](./contracts/openapi.yaml)
