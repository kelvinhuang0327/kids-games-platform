# 功能規格：幼兒網頁遊戲平台（MVP）

**功能分支**: `001-kids-games-platform`
**建立日期**: 2025-10-30
**狀態**: MVP 實作中
**版本**: v0.1 (純前端 MVP)

## 專案概述

建立一個針對 4-13 歲兒童的教育遊戲平台 MVP，使用純前端技術實作核心功能。

### MVP 範圍
- ✅ 分齡設計（4-6 歲 / 7-13 歲）
- ✅ 本地儲存遊戲進度
- ✅ 基礎家長控制功能
- ✅ 響應式設計
- ✅ 零追蹤、重隱私

### 未來擴展（完整版）
- ⏳ 後端 API（NestJS + PostgreSQL）
- ⏳ 雲端同步
- ⏳ 多人模式
- ⏳ 高級學習分析
- ⏳ COPPA/GDPR 完整合規

## 使用者情境與測試

### ✅ 使用者故事 1 - 兒童遊玩適齡遊戲（P0 - 已實作）

**情境**：5 歲兒童選擇年齡組後，看到專為其設計的遊戲，可以輕鬆開始遊玩。

**MVP 實作狀態**：
- ✅ 首頁年齡組選擇（4-6歲 / 7-13歲）
- ✅ 分齡遊戲大廳
- ✅ 拼圖遊戲（簡化版）
- ⏳ 迷宮遊戲
- ⏳ 互動漫畫
- ⏳ 其他遊戲

**驗收情境**：
1. ✅ **當** 選擇「4-6 歲」，**則** 顯示 3 個適齡遊戲（拼圖、迷宮、漫畫）
2. ✅ **當** 選擇「7-13 歲」，**則** 顯示 6 個遊戲（+數學、程式、EdX）
3. ✅ **當** 完成遊戲，**則** 顯示慶祝動畫與回饋
4. ✅ **當** 遊戲進度，**則** 自動保存到本地儲存

---

### ✅ 使用者故事 2 - 家長監控兒童活動（P1 - 部分實作）

**情境**：家長可以查看兒童的遊戲統計和進度，並管理資料。

**MVP 實作狀態**：
- ✅ 家長控制台入口（數學題驗證）
- ✅ 遊戲統計顯示
- ✅ 使用時間追蹤
- ✅ 清除資料功能
- ⏳ 時間限制執行（追蹤已實作，鎖定未完成）
- ⏳ 遊戲啟用/禁用
- ⏳ 學習報告圖表

**驗收情境**：
1. ✅ **當** 進入家長專區，**則** 需要回答簡單數學題（3+5=?）
2. ✅ **當** 驗證成功，**則** 顯示遊戲統計和進度
3. ✅ **當** 查看統計，**則** 看到總遊戲數、完成數、最佳分數
4. ⏳ **當** 設定時間限制，**則** 達到限制時自動停止遊戲

---

### 🎯 使用者故事 3 - 多遊戲體驗（P2 - 未來擴展）

**情境**：兒童可以體驗多種不同類型的教育遊戲。

**完整版規劃**：
- 🎯 數學挑戰（7-13 歲）
- 🎯 程式邏輯遊戲（7-13 歲）
- 🎯 顏色配對（4-6 歲）
- 🎯 形狀拼拼樂（4-6 歲）
- 🎯 記憶配對遊戲
- 🎯 EdX 教育資源整合

**驗收情境**（完整版）：
1. 🎯 **當** 進入遊戲大廳，**則** 可選擇 10+ 種不同遊戲
2. 🎯 **當** 完成所有類型遊戲，**則** 獲得成就獎章
3. 🎯 **當** 遊玩不同遊戲，**則** 系統追蹤學習進度

## 技術架構（MVP）

### 前端技術棧
```
React 18+ + TypeScript
├── Vite 5+ (建構工具)
├── Zustand 4+ (狀態管理)
├── React Router 6+ (路由)
├── Framer Motion 10+ (動畫)
├── Tailwind CSS 3+ (樣式)
└── Howler.js 2+ (音效 - 規劃中)
```

### 儲存方案
- **LocalStorage**: 所有資料本地儲存
- **無後端**: 零伺服器依賴
- **無雲端**: 資料不上傳

### 測試框架
```
Vitest 1+ (單元測試)
├── React Testing Library (組件測試)
├── @testing-library/user-event (互動測試)
└── jsdom (DOM 環境)
```

## 關鍵實體（MVP 簡化版）

### 1. Settings（設定）
```typescript
{
  ageGroup: '4-6' | '7-13' | null
  soundEnabled: boolean
  musicEnabled: boolean
  voiceEnabled: boolean
}
```

### 2. GameProgress（遊戲進度）
```typescript
{
  [gameId: string]: {
    completed: boolean
    bestScore: number
    bestTime: number
    attempts: number
    lastPlayed: string
  }
}
```

### 3. ParentalControl（家長控制）
```typescript
{
  dailyLimit: number      // 分鐘
  todayUsage: number      // 分鐘
  lastResetDate: string   // ISO date
  allowedGames: string[]
  disabledGames: string[]
}
```

### 4. GameConfig（遊戲配置）
```typescript
{
  id: string
  name: string
  displayName: string
  description: string
  icon: string
  ageGroups: AgeGroup[]
  difficulty: 'easy' | 'medium' | 'hard'
}
```

## 邊界情況處理

### MVP 階段
1. **網路離線**：✅ 所有功能本地運作，無影響
2. **資料遺失**：✅ 提供清除資料功能，可重新開始
3. **跨裝置同步**：⏳ MVP 不支援，未來功能
4. **多兒童檔案**：⏳ MVP 不支援，使用年齡組切換

### 未來處理
1. **同時登入**：需後端會話管理
2. **年齡過渡**：需家長控制完整實作
3. **時間限制**：需伺服器端執行
4. **隱私合規**：需法律審核
